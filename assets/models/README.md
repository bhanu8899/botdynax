# 3D robot model

Drop the downloaded `.glb` file here, named exactly:

    robot_vacuum.glb

Source: "Robot vacuum Cleaner Rob-vac" by darkfrei on Sketchfab
(https://sketchfab.com/3d-models/robot-vacuum-cleaner-rob-vac-7d904c05d4204d19a2940d9d6f21ef8d),
licensed CC-BY 4.0 — attribution to darkfrei is required and is included
in the app's About/Credits screen.

Once the file is here, run `flutter pub get` and the Home dashboard's
3D robot view will pick it up automatically — no code changes needed.
